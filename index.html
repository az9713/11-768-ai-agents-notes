Independent companion to CMU 11-768: AI Agents

AI agents, from action loops to policy optimization

These independent CMU 11-768 study chapters develop agent architecture, tool use, long-context computation, memory, planning, software and computer interaction, supervised fine-tuning, reinforcement learning, deep research agents, advanced RL algorithms, RL training systems, and agent safety. They are written for advanced graduate readers who have used agents but have not built them. A common mathematical model connects model proposals to authorization, execution, evaluation, training, and verification. Worked examples, executable definitions, limitations, exercises, and primary sources extend the recorded CMU 11-768 lectures.

Reading sequence

Chapters 1–4 construct a single-run harness. Chapters 5–7 study how it plans and acts in complex environments. Chapters 8–9 explain how trajectory data changes the underlying policy. Chapter 10 applies that evaluation and training machinery to deep research agents. Chapters 11–12 extend training to stale data, clipped updates, unreliable rewards, and the systems that run them. Chapter 13 returns to the authorization boundary and asks how to limit, monitor, and test what an agent can do. A timestamp beside a section title opens the corresponding source segment. Research findings and primary-source citations are integrated into the exposition.

Cumulative Python harness

Each chapter develops part of one executable Python package. Chapters 1–4 define the run state, permission-checked tools, context management, and memory. Chapter 5 adds dependency plans, reliability diagnostics, replanning decisions, and work/span bounds. Chapters 6–7 add behavioral evaluation measures and coordinate transforms. Chapters 8–9 add masked supervised loss, effective data mixtures, reward-to-go, a Monte Carlo policy-gradient estimator, and group diagnostics. Chapter 10 adds chance-corrected rater agreement, citation accuracy and recall, and a contrastive retrieval loss. Chapter 11 adds generalized advantage estimates, importance-weight moments, PPO and CISPO gradient coefficients, and KL divergence. Chapter 12 adds batching makespans, bfloat16 rounding, and a tokenizer round trip. Chapter 13 adds cross-run reach through shared state, alert precision, and a zero-failure bound on harm rates. The package uses only the Python standard library and deterministic examples, so readers can reproduce every behavior without credentials.

Read the companion code guide and run python -m unittest discover -s tests -v from the repository root. The behavioral checks cover execution boundaries as well as the planning, evaluation, and training equations. The package is an educational harness. It is not a production runtime or a provider-specific integration.
