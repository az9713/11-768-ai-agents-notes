  • Three choices are settled. The links are fixed. The licence is MIT. You chose to contact no one. The open decisions each have a recommended default (section 12).

The ten rules that matter most

  1. Treat the transcript as the spine. Never treat it as the prose.
  2. Put a recording timestamp on each main heading. Put no other reference to the recording anywhere.
  3. Open each chapter with one concrete task and its consequence. Reuse that task in every later section.
  4. Define every term and symbol before its first use. A glossary cannot repair a late definition.
  5. For each central result, state the question, derive it, interpret it in words, test it on numbers, and state its limit.
  6. Cite primary sources inside the argument, beside the claim each one supports.
  7. Put code after the model it implements. Extend the cumulative agent_lab package and add a test.
  8. Write full solutions to the exercises. Show the reasoning.
  9. Finish one chapter at full depth before you start the next.
  10. Treat the validator as a structure check. It does not measure depth.

"""Acquire time-coded captions for the available CMU playlist videos."""

import json
from datetime import datetime, timezone
from pathlib import Path

from youtube_transcript_api import YouTubeTranscriptApi


VIDEOS = [
    ("UwfjzyLnvMg", "What are Agents and How Do They Work?"),
    ("jXChFB4JSyw", "Tool Use for Language Model Agents"),
    ("AiwCCvFW1uE", "Long Context Modeling for Agents"),
    ("6zigF2a-2Pw", "Memory and Skills for Agents"),
    ("S8v-dR4s29M", "Planning, Task Decomposition, and Multi-Agent Coordination"),
    ("1BWeH1oOM7k", "Agents for Coding and Software Development"),
    ("jwGluLrrqjQ", "Computer Use Agents"),
    ("O3HSU0AoILc", "Supervised Fine Tuning"),
    ("paAcPaaYZGM", "Reinforcement Learning Basics"),
]


def main():
    root = Path(__file__).resolve().parent
    api = YouTubeTranscriptApi()
    manifest = []
    for index, (video_id, title) in enumerate(VIDEOS, 1):
        tracks = api.list(video_id)
        available = [
            {"language_code": t.language_code, "is_generated": t.is_generated}
            for t in tracks
        ]
        english = [t for t in tracks if t.language_code.startswith("en")]
        if not english:
            raise RuntimeError(f"No English captions for {video_id}: {available}")
        track = sorted(english, key=lambda t: (t.is_generated, t.language_code != "en"))[0]
        fetched = track.fetch()
        segments = [
            {"start": item.start, "duration": item.duration, "text": item.text}
            for item in fetched
        ]
        file_stem = f"lecture-{index:02d}"
        (root / f"{file_stem}.json").write_text(
            json.dumps(segments, ensure_ascii=False, indent=2), encoding="utf-8"
        )
        with (root / f"{file_stem}.txt").open("w", encoding="utf-8") as out:
            for item in segments:
                minute, second = divmod(int(item["start"]), 60)
                out.write(f"[{minute:02d}:{second:02d}] {item['text']}\n")
        record = {
            "lecture": index,
            "title": title,
            "video_id": video_id,
            "url": f"https://www.youtube.com/watch?v={video_id}",
            "caption_language": track.language_code,
            "caption_generated": track.is_generated,
            "available_tracks": available,
            "segments": len(segments),
            "last_caption_end_seconds": round(
                segments[-1]["start"] + segments[-1]["duration"], 2
            ),
            "retrieved_utc": datetime.now(timezone.utc).isoformat(),
        }
        manifest.append(record)
        print(json.dumps(record, ensure_ascii=False))
    (root / "manifest.json").write_text(
        json.dumps(manifest, ensure_ascii=False, indent=2), encoding="utf-8"
    )


if __name__ == "__main__":
    main()

8. Voice and prose

The voice is that of an editor of graduate textbooks. It is impersonal, present-tense, and exact. The measures below come from the nine chapters, prose only (code, display math, tables, and lists excluded).

  • No first or second person in running prose. "we", "you", and "our" occur 0 times in 38,725 prose words. "professor" and "lecturer" occur 0 times. Three exceptions exist in lines that my prose count excludes. One is "tells us" (chapter 3, line 19). One is "How would you represent" in an exercise (chapter 4, line 222). One is a quoted attack string with "your credentials" (chapter 7, line 190). Do not add more.
  • Short sentences. Chapter means run from 12.7 to 15.0 words. Chapter medians run from 12 to 14. The longest sentence in a chapter runs from 33 to 52 words.
  • Objects are introduced with "Let". 167 sentences open with "Let", 18 with "Define", and 8 with "Consider".
  • Each paragraph makes one move. A paragraph states a result, then explains the mechanism, then gives the consequence or the limit. These are separate sentences.
  • Terms are fixed. A defined word keeps one meaning. The chapters do not use proposal, action, decision, and execution as synonyms, because they name different stages of the harness.
  • Modal verbs carry meaning. Must marks an invariant. Can marks capability. May marks uncertainty. Should marks a recommendation.
  • Equations are sentences. An English lead-in introduces the display, the display ends with its punctuation, and the next sentence interprets it.
  • Numbers replace praise. The text gives "approximately 0.634", not "high". It uses prove only for formal deduction.

One design rule runs through every chapter. agent_lab/README.md states it:

a model proposes, the harness authorizes, an environment executes, observations update the next decision, and a verifier decides whether the run has completed.

The gate uses trusted evidence e_t, never the hidden state s_t. A service must still re-check its own precondition at commit time.

  • The draft must define every term before use. It must avoid the symbol collisions with chapters 1 and 9: phi, lambda, delta, tau, and G. It must tie each claim to a transcript passage.
  • A weak draft costs more tokens later, because each correction round reads the whole chapter again.

Why not a higher effort

  • Do not use xhigh or max for the whole job. No evidence shows that they improve this task. They increase the reasoning tokens on every call.
  • Use xhigh only if the lecture 10 review finds reasoning errors that high made.
  • Fable 5.1 may give a better draft than Opus 5.5. It was not tested, and its price is unknown. Test it only if you accept an unknown cost.

What drives token use

  • The transcripts are the largest input. Keep them in files. Let a Sonnet subagent write a short source map with timestamps. The drafting context then holds the map and the cited passages, not the full transcript.
  • Effort changes the reasoning tokens. It does not change the input size. The input size is the larger lever.
